# Tidywells

Open-source tools for Canadian oil and gas public data: clean regulator files (AER, Petrinex, BCER, Saskatchewan) into one schema, and run simple decline curve forecasts. You use your own downloaded files, and they stay on your machine.

**Not affiliated with any regulator.** Outputs are illustrative only, not for reserves reporting or investment decisions.

## Status
Early scaffold. Decline engine first, loaders next.

## Layout
- `src/tidywells/` package (decline math, loaders)
- `tests/` tests on synthetic data only
- `docs/` static site (GitHub Pages)
- `posts/` write-ups

# Changelog

## Site (unreleased)
- Substack (https://tidywells.substack.com/) added alongside Medium: footer, home and Analysis promo, About buttons, end-of-post box, signup box, README.
- Navigation grouped into dropdowns (Tools, Research, Learn, About) generated on every page by `posts/build_feed.py`; Pro stays a highlighted link.
- About page: author photo and bio, and a "How this is made" section describing AI assistance and how figures are checked.
- Correction: new-well vintage study sorted wells into oil/gas with a rule that put most oil wells with associated gas in the gas group; now oil if at least half of output on an energy basis (6 Mcf per bbl). Post, pack table and conclusions updated.
- New analysis: first-year decline of new wells (`posts/decline_study.py`, `posts/gen_posts3.py`).
- Sitemap and robots.txt generated by `posts/build_feed.py`; optional cookieless analytics and sponsor strip (`docs/site.js`).
- Pro page, terms page, data guide, monthly data pack builder (`posts/build_pack.py`).
- Comments service for posts (`workers/comments`): anonymous, moderated, Cloudflare Worker + D1 + Turnstile.

## 0.1.0
- Loaders for Petrinex (AB, SK) and BCER files, join, monthly series.
- Bounded Arps fit, forecast with terminal switch, NPV.
- Analysis scripts: backtest, recovery, monthly aggregates.

## Site (unreleased), open data and trust
- Added an Open data page with a free monthly production CSV (units, sources, caveats, citation) and Dataset markup.
- Added a Corrections page and a 404 page; footer links on every page.
- Added Article and WebSite structured data, built by `posts/build_feed.py`, which also rebuilds the CSV and the sitemap.
- Fixed a broken Methods link in the Sponsor page nav.

- Added a Production explorer page (interactive monthly production chart, year-on-year and indexed views, CSV export) and an Explorer nav link on every page.
- Added a glossary, post search on the Analysis page, a cite and share block on every post, a latest-data strip on the home page (rebuilt each run from the monthly data), and a compare mode in the decline-curve tool.
- Explorer: shareable links (view saved in the URL), embed code for any chart, and a seasonally adjusted view.
- Added posts/verify_site.py (checks 800 published figures against the dataset, writes docs/data/manifest.json), a CI workflow, CITATION.cff, CONTRIBUTING.md, issue templates, and a "How we check this" section on the open-data page.

File cleaner

Drop a file you downloaded from Petrinex (Alberta or Saskatchewan Conventional Volumetrics) or the BC Energy Regulator (production data) and get one tidy CSV: one row per well, month and product, with IDs kept as text. Everything runs in your browser. Your file is never uploaded.

Drop files here, or click to choose.csv or .zip, one or several files of the same kind. Large files are read in pieces.
Products

Showing the first 10 rows. Volumes: oil and condensate in m³, gas in 10³ m³. Open the CSV in Excel with “Import from text” and set the ID columns to Text, or Excel will strip leading zeros.

What it does

  • Alberta and Saskatchewan: keeps well-level production rows only (activity PROD, well IDs), for the products you pick. Rows where the regulator masked the well ID (***) are dropped and counted.
  • BC: skips the title line, sums the zones of each well into one row per well, month and product, and keeps zero-volume months as zeros.
  • IDs stay text, so leading zeros survive.
  • Same rules as the Python package. The test suite runs this page's code and tidywells.read_volumetrics / read_bc_production on the same files and requires identical rows. See the Methods page and the code.

Very large files (hundreds of MB of CSV) can take a minute and need free memory; if the tab runs out, clean one month at a time. Informational only, not investment, legal or engineering advice.

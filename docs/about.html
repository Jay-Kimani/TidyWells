About Tidywells

Tidywells is a small open-source project that makes Canadian oil and gas regulator data easier to work with. It has three parts: a Python package that loads and cleans public well and production files into one consistent layout, a browser tool for fitting a decline curve to a well, and plain-language analysis built on the same code.

Why

Alberta, Saskatchewan and British Columbia all publish useful data, but in different layouts, with leading-zero IDs that spreadsheets damage, duplicate rows, and codes that need a lookup table. Most of the work is cleaning. We would rather do that once, in the open, and show how reliable the simple tools built on top really are.

Principles

  • Your files stay yours. The tools work on files you download. We do not host regulator data, and the web tool never uploads anything.
  • Show the work. Every analysis links to the code that produced it, and the Methods page lists the sources and rules.
  • Say what it can't do. Results are illustrative, not for reserves reporting or investment decisions, and we publish the limits next to the results.

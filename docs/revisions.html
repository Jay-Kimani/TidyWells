Data revisions

Regulators sometimes restate production for months they already published. If you build on a number without knowing that, you can be quietly wrong. Every time our open dataset changes we keep the earlier version, compare the two and log what moved. Nobody else publishes this for Canadian production data.

How it works

  • Each version of the open dataset is saved under docs/data/vintages/ with its SHA-256 fingerprint.
  • A script compares the new version with the previous one and writes every restated or new month to revisions.json.
  • Limit: we can only see a revision in a month we re-downloaded. Each release we re-pull the most recent months, not the whole history, so a late restatement of an old month can go unseen.
